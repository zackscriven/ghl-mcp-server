Version-header distribution why one global header could never work

Every tool sends the Version header its own spec documents — 494 × v3, 117 × 2021-07-28, 10 × 2021-04-15, 30 × none (e.g. the store spec defines no Version header at all). GHL runs all of these tiers concurrently; a wrapper that hardcodes one value silently breaks whole domains.
