## LinkedIn / Facebook (longer)

I got tired of GoHighLevel MCP wrappers that cover 5% of the API and silently drop fields — so I built the whole thing.

ghl-mcp-server: the full GoHighLevel API as MCP tools.

→ 651 tools, generated from all 84 official OpenAPI specs (667 operations enumerated — the 16 that aren't tools are itemized exceptions, not silent gaps)
→ Every documented request field exposed. Schemas carried verbatim from the specs, so nothing gets hand-transcribed away
→ GHL runs three API version tiers at once (v3, 2021-07-28, 2021-04-15) — the right Version header is resolved per operation, never hardcoded
→ Pagination that actually pages, multipart uploads that actually upload
→ Writes blocked by default behind a dry-run safety gate — point it at a production CRM without sweating
→ TypeScript, stdio, multi-tenant (locationId per call), works with Claude, Codex, and any MCP client

If you're building AI agents on top of GoHighLevel, this is the connector I wished existed.
